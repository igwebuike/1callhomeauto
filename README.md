# 1Call Home Auto — Local Test

This is a static responsive website, so you do not need Node/Vite to test it.

## Fastest
Double-click `index.html`.

## Better local server (Windows)
Open Command Prompt in this folder and run:

    py -m http.server 8080

Then open:

    http://localhost:8080

Phone links use 214-903-2157 and text buttons pre-fill a service request.

Files:
- index.html
- styles.css
- script.js
- design-reference.png (visual concept only)


Contact email: 1callhomeauto@gmail.com

## Render deployment
Create a Render **Static Site** from the GitHub repository. No build command is required. Publish directory: `.`

## Custom domain
After the Render site is live, add `1callhomeauto.com` and `www.1callhomeauto.com` under Render Settings > Custom Domains. Render will show the exact DNS records to add in GoDaddy.
